## Implemented behavior

New Standard manifests select scene-av-v1. FFmpeg cuts each authoritative scene into a silent native MP4 and, when an audio track exists, a WAV. Spark1.3 interprets the isolated moving video and reads visible text; Muse Voice Transcribe1.0 transcribes that scene's audio. Shared interpretation runs once per scene. Each persona receives only its current frame, scene-local video observations/text/transcript and its own prior impression. A skipped persona receives no later scene. Notes receive the saved scene context alongside supported persona evidence. Source hashes and approximate turn timing travel with features.

Preparation has durable dispatched/accepted markers, stored accepted outputs, a renewable lease, bounded media/calls and the existing global concurrency gate. Accepted units are reused; ambiguous/failed preparation units are not resent. Clips are inline and audio is multipart, so this path creates no Files API IDs. Raw responses and derivatives enter the existing owned deletion inventory. Reports derive model IDs, speech/visual-text coverage, usage, cost estimates and disclosures from the actual path. Old manifests/reports retain their visual-only behavior and disclosure; they are not silently upgraded. Audio-free uploads skip Voice Transcribe. Muse Image thumbnails, Wonder and SAM remain outside this V03 integration; no claim that those roadmap features were implemented.
